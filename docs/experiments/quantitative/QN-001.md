# QN-001 — Comparing ABA Learning strategies on minimal causal motifs

## Status

`proposed`

## Purpose

QN-001 is the first proposed strategy-comparison experiment. Its purpose is to compare greedy and non-deterministic ABA Learning strategies on minimal causal motifs, if the current implementation supports this cleanly or after Cursor identifies the required configuration path.

This experiment is motivated by supervisor guidance that greedy ABA Learning may behave better for learning causality, but that this has not yet been demonstrated properly in the project context.

QN-001 should be framed as a comparison of ABA Learning strategy behaviour on parent-set / learned-rule recovery tasks. It should not be framed as a full causal discovery evaluation.

## Research question

TBD after QL-001 and Cursor inspection.

Working form:

> On minimal three-node causal motifs, does greedy ABA Learning recover parent-like learned-rule bodies more reliably or efficiently than non-deterministic ABA Learning?

## Theoretical motivation

This experiment investigates whether the choice of ABA Learning strategy affects the ability of the current bridge to recover causal-parent-like rule bodies.

Separate the following:

- **ABA foundations:** the experiment concerns learned ABA frameworks and accepted/rejected target claims.
- **ABA Learning / ABALearn:** the experiment compares learning strategies within the ABA Learning pipeline.
- **Causal ABA / argumentative causal discovery:** the experiment is causally motivated, but does not test full Russo-style Causal ABA unless the implementation uses arrow/no-edge/independence assumptions, d-separation, and stable extensions as DAGs.
- **Current `aba_asp/causal` implementation:** the experiment uses the current bridge as a target-wise learned-rule / parent-set recovery pipeline.

- d-separation is implemented;
- causal graph recovery is achieved;
