# QL-001 — Qualitative inspection of ABA Learning on minimal causal motifs

## Status

`proposed`

## Purpose

QL-001 is the first supervisor-aligned qualitative experiment. Its purpose is to inspect what the current ABA Learning bridge learns on small, controlled three-node causal motifs.

This experiment is intended to support the interim report by providing a concrete, narratable investigation of learned ABA rules. It is not intended to establish full causal discovery or full Russo-style Causal ABA.

## Research question

TBD after focused design.

Working form:

> When tabular data is generated from simple three-node causal motifs and the current `aba_asp/causal` bridge learns target rules target-by-target, what rule bodies are recovered, and when do those bodies correspond to true causal parents rather than non-parent predictive associations?

## Theoretical motivation

This experiment sits at the intersection of ABA Learning and causal discovery, but it must be framed cautiously.

- **ABA foundations:** the learned framework consists of rules, assumptions, contraries, attacks, and accepted/rejected claims under the learner’s semantics.
- **ABA Learning / ABALearn:** the experiment uses the inherited ABA Learning machinery to learn rules from background knowledge and positive/negative examples.
- **Causal ABA / argumentative causal discovery:** this experiment is motivated by causal discovery, but it does not test full Russo-style Causal ABA unless the implementation explicitly uses arrow/no-edge/independence assumptions, d-separation reasoning, and stable extensions as candidate DAGs.
- **Current `aba_asp/causal` implementation:** the current bridge is treated as an ABA Learning-based learned-rule / parent-set recovery pipeline over tabular data.

The qualitative focus is important because aggregate metrics alone may hide whether learned rules correspond to true parents, ancestors, children, descendants, or merely predictive associations.

## Relation to Causal ABA

This experiment may show whether learned ABA rules recover causal-parent-like structure in a controlled setting.

It does **not** show full Causal ABA unless the code path explicitly includes:

- `arr` / `noe` assumptions;
- independence assumptions;
- d-separation reasoning;
- stable extensions interpreted as candidate DAGs.

Until such implementation evidence exists, QL-001 should be described as a qualitative parent-set / rule-body recovery investigation.
