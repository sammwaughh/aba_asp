## Purpose

m1.1 is a metamorphic validity control on the QL2 (QI-002) parent-recovery
proxy. It tests whether the existing target-wise ABA Learning behaviour follows
the variable that occupies the direct-parent role, rather than a fixed variable
identity (e.g. `x0`) or a fixed learner-visible representation position. This
record covers fixture generation, Stage-0 validation, and the first eight-cell
learning grid run. It is an ABA Learning-based parent-set / learned-rule recovery
investigation, NOT Russo-style Causal ABA.

## Research question

> Under complete, noiseless QL2-style target-mechanism tables, when the
> direct-parent and ancestor roles are exchanged between `x0` and `x1`, and the
> learner-visible predictor order is independently reversed, does the learnt
> `x2` rule follow the variable occupying the direct-parent role?

Stage-0 established that the eight fixtures are correctly constructed and that
the requested predictor order is exposed in the learner-visible BK. The learning
run (below) supplies the learner outcomes for Stage 1–3 inspection.

## Theoretical motivation

- **ABA foundations:** assumptions, contraries, attacks, extensions — unchanged.
- **ABA Learning / ABALearn:** transformation-rule learning from BK and E+/E-;
  the fixed strategy is QI-002-style non-deterministic folding.
- **Causal ABA / argumentative causal discovery:** NOT exercised here (no
  arr/noe/indep, no d-separation, no stable-extension-as-DAG).
- **Current `aba_asp/causal` implementation:** tabular data → feature-predicate
  BK → per-target learning → compare learnt body against the known parent.

The QL2 categorical chain returned a rule referring to `x0` where the expected
direct parent was `x1`. m1.1 separates three explanations: direct-parent-role
tracking, fixed variable identity, and fixed representation position, by crossing
parent identity with learner-visible predictor order.

## Relation to ABA Learning

- Target predicate: `x2`, excluded from BK.
- E+/E-: fixed per fixture (binary positive `x2==1`; cat3 positive `x2==2`).
- BK: feature predicates per predictor (binary bare `x0(A)`; cat3 `x0_val_v(A)`).
- Strategy (fixed for the run): `folding_mode: nd`, `folding_steps: 15`,
  `prolog_timeout_s: 120`.

## Relation to Causal ABA

This experiment tests whether learnt ABA rules track a known direct-parent role
under identity (`pi`) and representation-order (`sigma`) transformations. It does
NOT test full Russo-style Causal ABA, causal discovery, or whole-graph recovery.

## Representation-order finding (key)

The learner-visible predictor order is the **DataFrame column order**.
`generate_aba_background_knowledge` serialises BK by iterating `for col in
df.columns` and skipping the excluded target; there is no sort or canonicalisation
in the bridge (`causal/argcausaldisco_integration.py`) or in
`utils/data_utils.py`, and `execute_cell_stage1` preserves order via
`fx.df.copy()`. So reversing predictor order is implemented as a fixture column
reorder (`x2` kept last), and this propagates verbatim into `bk.aba`. No engine
or BK-writer change was needed. Stage 3 inspection (cat3 A vs B) showed that nd folding’s first
literal tried follows BK predicate-block order, which determines the entailment vs assumption branch
when cat3 σ-pairs differ at rule level.

## Dataset / data-generating process

### Source

- Handcrafted fixtures; canonical cell A built in `handcrafted_m11.py`, with
  cells B/C/D derived from A via `sigma` and `pi`.

### Graph / structure

```text
Cell A/B: x0 -> x1 -> x2   (direct parent of x2 = x1; x0 upstream ancestor)
Cell C/D: x1 -> x0 -> x2   (direct parent of x2 = x0; x1 upstream ancestor)
```

The exhaustive factorial over `(x0, x1)` deliberately decorrelates the ancestor
from the parent, so the non-parent cannot succeed by spurious correlation. This
is NOT a faithful chain SCM sample (a correlated-ancestor test remains the job of
QI-003/QI-004); m1.1 only tests parent-rule recovery when the parent is the
unique separator, plus `pi`/`sigma` equivariance.

## Design inheritance audit (vs QL2 / QI-002)

The fixtures inherit structure from QI-002. The audit below records which
inherited choices are principled and which were corrected for m1.1. Reducing the
per-assignment repeat to 1 (minimal complete factorial; 4 binary / 9 cat3 rows)
does not change separator logic or `pi`/`sigma` validity. Code evidence: the
learner imposes no `|E+| >= 2` requirement (`rote_learning.pl` has only a
`sort/2`, no example-count guard), and QI-001's chain-binary fixture already ran
a 4-row full factorial successfully (register: QI-001 "9/9 solved"). Even at one
row per assignment, the x1-parent binary cell has `|E+| = 2` and cat3 has
`|E+| = 3`.

| Design choice | QI-002 / QL2 | m1.1 current | Principled? | Recommendation |
|---|---|---|---|---|
| Full factorial over `(x0,x1)` | yes | yes | yes | keep |
| `x2` per-assignment repeat | yes ("avoids single-row flukes", weak) | corrected to `_REPEATS = 1` | no (no separator / `pi`/`sigma` effect; no engine requirement) | removed (minimal factorial) |
| Single orientation vs `pi`/`sigma` cells | single canonical orientation per motif | adds `pi`/`sigma` cells (A/B/C/D) | yes | keep (good inheritance) |
| Decorrelated `x0` vs faithful chain | decorrelated factorial (not a faithful chain SCM) | same | yes for the unique-separator question | keep; document the boundary (faithful chain = QI-003/QI-004) |
| Binary positive-only BK | bare positive-case predicate `x0(A)` for `{0,1}` | same via shared BK writer | yes (existing encoding contract) | keep unchanged |

### Transformation orbit (per encoding)

```text
A --sigma--> B
|             |
pi            pi
v             v
D --sigma--> C
```

- `sigma`: reverse learner-visible predictor order; values/examples/ids/roles/target unchanged.
- `pi`: exchange `x0`<->`x1` (names and values together); relabel edges via 0<->1; fix `x2` and sample ids.
- `B = sigma(A)`, `D = pi(A)`, `C = sigma(D) = pi(B)`.

## Interpretation notes

### Facts

- Eight fixtures from canonical A via verified σ/π; Stage-0 all PASS; BK order matches table order.
- 8/8 solved; 6/8 exact expected singleton; cat3 A/D discrepant.
- Binary: all four σ and π edges hold at rule level with correct coverage.
- Cat3: σ fails on both edges; π holds on B↔C only; A/D both discrepant.

### Binary (bounded conclusion)

Under the tested binary fixtures and fixed nd configuration, returned rules track the direct-parent role across π swaps and are invariant to the tested learner-visible predictor order (σ). This is evidence **for** parent-role tracking in the binary encoding under these controls. Not causal discovery.

### Cat3 (bounded conclusion)

Under the tested cat3 fixtures and fixed nd configuration, σ-invariance **fails**: reversing predictor order while fixing parent identity (A↔B, D↔C) changes whether the learner returns the expected singleton or an assumption-based rule citing the non-parent. π-equivariance holds on the successful pair B↔C only. The failure is **encoding-dependent** (binary passes; cat3 does not). Triggered inspection points to BK serialisation order → first nd-fold literal → entailment branch as the observable mechanism. Not causal discovery.

### Overall (bounded conclusion)

m1.1 answers its central question **conditionally**: direct-parent tracking with representation-order invariance holds for **binary** but not for **cat3** under fixed non-deterministic folding. This separates a pure fixed-name artefact from a representation-order effect in the categorical encoding.

### Uncertainties

- Whether a different nd fold literal order would recover cat3 A/D without assumptions (not tested).
- Greedy folding may change cat3 behaviour (M1.2; not established here).

## Claims supported

- Fixtures, σ/π orbits, BK order propagation, and minimal factorial design (Stage 0).
- All eight cells solved with complete artefacts.
- Binary: exact expected rules; σ and π hold; cov_py and cov_pl agree.
- Cat3 B/C: exact expected rules; π B↔C holds.
- Cat3 σ fails at rule level (A↔B, D↔C); triggered inspection documents BK-order → first-fold-literal → entailment fork on cat3 A vs B (and analogously D vs C).
- Encoding-dependent split: binary positive control; cat3 representation-order sensitivity under nd.

## Claims not supported

- Uniform direct-parent tracking across both encodings.
- σ-invariance or full π-equivariance on cat3.
- Causal discovery or whole-graph recovery.
- Full Russo-style Causal ABA.
- Correlated-ancestor / faithful chain SCM behaviour (QI-003/QI-004 territory).
- Greedy folding fixes cat3 σ failure (M1.2 hypothesis only).
