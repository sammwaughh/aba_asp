# QI-002 — Minimal truth-table baseline for x2 parent recovery

## Status

`proposed | planned | implemented | run | analysed | reported`

Current status: `implemented` (fixtures, config, metrics, summary script, and tests in place; ABA Learning not yet run).

## Purpose

QI-002 establishes a *minimal but principled* baseline for target-wise parent-set recovery of `x2` under the current `aba_asp/causal` ABA Learning bridge. It replaces the ad-hoc tiny tables of the QI-001 pilot (4-5 rows, not justified) with *complete truth tables*: every combination of the two candidate predictors `(x0, x1)` is present, repeated twice, with a noiseless target. This guarantees the true parent is the unique zero-error separator, so a genuine causal rule is learnable *in principle*. The question is whether the learner finds it in the best possible case.

This is an ABA Learning-based parent-set recovery investigation, NOT Russo-style Causal ABA.

## Research question

> Under complete, noiseless truth tables generated from three 3-node motifs (chain, fork, collider), where the true parent of `x2` is the unique perfect separator of the positive class, does the current ABA Learning bridge learn a target rule for `x2` whose body variables equal the true direct parents, and under what failure modes?

## Theoretical motivation

- **ABA foundations:** assumptions, contraries, attacks, extensions.
- **ABA Learning / ABALearn:** transformation-rule learning from BK + E+/E-.
- **Causal ABA / argumentative causal discovery:** Russo-style arr/noe/indep, d-separation, stable-extension-as-DAG — NOT used here.
- **Current `aba_asp/causal` implementation:** target-wise learned-rule / parent-set recovery over `handcrafted_table` fixtures.

The minimal-baseline logic: a table can only force the parent rule if the parent perfectly separates E+/E- while every non-parent does not. The complete factorial is the smallest design with that property (see the dossier README for the size derivation).

## Relation to ABA Learning

- BK built from the non-target columns (`x0`, `x1`); target `x2` excluded.
- E+/E- fixed by the fixture (positive class = `x2 == 1` binary, `x2 == 2` cat3).
- Target predicate: `x2`.
- Learner config: default non-deterministic folding, `folding_steps: 15`.

## Relation to Causal ABA

This experiment tests whether learned ABA rule bodies recover causal-parent-like structure on controlled tables. It does NOT test full Russo-style Causal ABA (no arr/noe/indep, no d-separation, no stable-extension-as-DAG).

## Confound treatment (corrected framing)

QI-002 makes a *principled, data-level correction* against the x0/first-column confound identified in QI-001 — it does **not** merely defer it. The complete factorial over `(x0, x1)` with a noiseless target makes every non-parent column statistically independent of `x2`, so the true parent is the unique zero-error separator and a non-parent has no legitimate (data-level) claim to the rule body. This eliminates the *data-level* mechanism of the confound: in QI-001 a non-parent such as the chain ancestor `x0` could look justified because the tiny/degenerate table left it correlated with `x2`.

A direct consequence: the canonical **chain** cell (parent `x1`, with `x0` now provably uninformative, `x0 ⊥ x2`) becomes a genuine probe of any residual *positional* x0-preference. Cross-cell logic: a learner that merely prefers `x0` predicts fork-pass + **chain-fail**; genuine parent recovery predicts both pass. These are different, falsifiable predictions, so QI-002 *can* test the confound rather than being blind to it. Observed in the completed run (see `QI002_minimal_motifs_summary.md`): binary recovers `{x1}` on the chain (inconsistent with a pure x0-bias), while cat3 cites the uninformative `x0` on the chain (consistent with an x0/ancestor artefact).

What QI-002 does **not** do — and what is left to QI-003/QI-004 — is: (i) resolve the **fork** in isolation, because the fork's true parent *is* `x0`, so positional bias and genuine recovery coincide there; (ii) test recovery against a *genuinely correlated* ancestor, because the factorial removes that correlation (it arguably over-corrects); and (iii) provide a **symmetric, within-structure parent-position swap** (`*_x0parent` vs `*_x1parent`). So QI-002 addresses the confound at the data level and yields partial evidence about positional bias, but does not provide the full symmetric/empirical break — that is QI-003/QI-004's job. QI-002 remains the "can the perfect rule be learned at all?" baseline.

## Dataset / data-generating process

### Source

- handcrafted fixture; generators in `causal/experiments/handcrafted_qi002.py`.

### Graph / structure

```text
chain:    x0 -> x1 -> x2          parents(x2) = {x1}
fork:     x0 -> x1, x0 -> x2      parents(x2) = {x0}
collider: x0 -> x2, x1 -> x2      parents(x2) = {x0, x1}
```

### Sample sizes

- binary: 8 rows (4 `(x0,x1)` combinations x2);
- categorical-3: 18 rows (9 combinations x2).

### Seeds

- Deterministic tables (no RNG); grid `seed: [0]`.

### Noise / stochasticity

- None. Targets are deterministic functions of the parents (chain `x2=x1`; fork `x2=x0`; collider binary `x2=x0 AND x1`, cat3 `x2=max(x0,x1)`).

## Encoding

### Target variable(s)

| Target | True parents | Target type | Reason for inclusion |
|---|---|---|---|
| `x2` | chain {x1}, fork {x0}, collider {x0,x1} | has-parents / collider | the recovery target |

### Background knowledge

- Target excluded from BK: `yes`
- Binary features (`{0,1}`) encoded as: bare predicates `x0(A)`
- 3-valued discrete features encoded as: value predicates `x0_val_v(A)`
- Continuous features: not used in QI-002
