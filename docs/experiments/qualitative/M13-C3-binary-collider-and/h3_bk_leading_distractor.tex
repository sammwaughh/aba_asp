\section{Research question}

On a BD AND collider with BK-leading independent isolated root \(A\), does
ECAI learning of target \(c\) select \(a\) in the first fold and retain \(a\)
in the final ABA framework rather than returning the evaluator-only rule
\texttt{c(A) :- b\_val\_1(A), d\_val\_1(A).}?

\section{Main finding (lead)}

On frozen sample \texttt{n30\_seed42}, ECAI \textbf{solves} target \(c\), but
BK-leading isolated \(a\) is pulled into the learned theory.

Decisive first fold:
\begin{verbatim}
folding result: c(A) <- [a_val_1(A)]
\end{verbatim}
then assumption introduction of \(\alpha_1\).
Both ordinary target rules remain conditioned on \(a\).
Emitted delta:
\begin{verbatim}
c(A) :- alpha_1(A), a_val_1(A).
c(A) :- alpha_2(A), a_val_0(A).
c_alpha_1(A) :- b_val_0(A).
c_alpha_1(A) :- alpha_3(A), b_val_1(A).
c_alpha_2(A) :- d_val_0(A).
c_alpha_2(A) :- b_val_0(A).
c_alpha_3(A) :- alpha_1(A), a_val_1(A).
\end{verbatim}
(plus \texttt{assumption}/\texttt{contrary} declarations).

\section{Secondary finding (brave residual)}

ECAI brave \texttt{solved} can be sample-adequate via \textbf{per-row
assumption choice} even when BK features do not determine the target.

\(\alpha_1\)--\(\alpha_3\) repair.
The \(a{=}0\) / \texttt{c\_alpha\_2} side is more BK-readable.

(\path{m13_bucket3_binary_collider_and}).

Bound: \textbf{\texttt{solved} + audit SAT \(\neq\) BK\(\to\)target predictor
recovered / mechanism-aligned.}
