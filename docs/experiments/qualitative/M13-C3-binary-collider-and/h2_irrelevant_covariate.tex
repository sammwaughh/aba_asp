\section{Research question}

On an AND collider extended with an independent isolated binary root \(D\),
does AAMAS learning of target \(c\) retain irrelevant \texttt{d\_val\_*}
literals in the learned bodies rather than returning the evaluator-only
\(D\)-free rule \texttt{c(A) :- a\_val\_1(A), b\_val\_1(A).}?

\section{Main finding (lead)}

On frozen sample \texttt{n30\_seed42}, AAMAS \textbf{solves} target \(c\) with:
\begin{verbatim}
c(A) :- a_val_1(A), b_val_1(A), d_val_1(A).
c(A) :- a_val_1(A), b_val_1(A), d_val_0(A).
\end{verbatim}

\textbf{Irrelevant \(D\) is included} in the learned representation of \(c\).
The run is solvable, but the delta is \textbf{not} the minimal /
mechanism-aligned \(D\)-free AND.

Brief H0 contrast: on the three-variable fixture without \(d\), AAMAS \(c\)
emitted the \(D\)-free AND; with an extra BK block for isolated \(d\), greedy
retains \(d\).

One-line corrective on ``still solvable'': the failure mode under test is
\textbf{distractor retention / failure of minimality}, not unlearnability of
\(c\).

Procedural one-liner: AAMAS greedy with \texttt{folding\_space(bk)} exhausts
matching BK literals including trailing \(d\), so catalogue bodies keep
\texttt{d\_val\_*} (see \texttt{prolog.stdout} for target \(c\)).
