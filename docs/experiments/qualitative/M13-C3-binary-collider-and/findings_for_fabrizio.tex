\begin{abstract}
The investigation asks what target-wise ABA Learning does when given only a
finite binary table sampled from a known causal data-generating process. The
principal process is a binary collider \(A\rightarrow C\leftarrow B\) with
independent stochastic roots and a deterministic AND child \(C=A\land B\).
The graph, mechanisms, population distribution, finite sample,
learner-visible encoding, learned ABA framework, and evaluator-only reference
are kept separate throughout.

The experimental sequence is recorded under labels H0--H7b for reference.
It begins with a baseline comparison of the published Greedy and
non-deterministic configurations across all targets on one frozen table
(H0), then introduces one controlled question at a time: finite-sample
support (H1); an irrelevant trailing covariate (H2); background-knowledge
order with a leading distractor (H3); brave versus cautious learning
(H4--H5); folding-token budget and grounded sample size (H6); and the
\code{relto} versus \code{sechk} assumption-introduction options (H7).
This document records what each probe was intended to reveal, its principal
signal, and the procedural explanation supported by the generated deltas and
Prolog traces.
\end{abstract}

\section{Purpose, scope, and organising question}

\subsection{Research question}

\begin{quote}
For a finite binary table generated by independent stochastic roots and
deterministic non-root mechanisms, and for each observed variable taken in
turn as the learning target: what ABA framework does \ABALearn{} emit under
the configurations studied here, and how does that framework relate to the
evaluator-only mechanism reference and to the information present in the
population and in the sample?
\end{quote}

The purpose is to describe how the learner transforms the supplied table into
rules, assumptions, and contraries, and to classify each emitted theory
against a target-dependent evaluator reference. On the principal AND
collider \(A\rightarrow C\leftarrow B\), only the deterministic child \(C\)
has a desired learned rule over its observed parents:

\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A).
\end{lstlisting}

The roots \(A\) and \(B\) are generated by independent stochastic mechanisms.
There is no underlying deterministic rule relating either root to the other
observed variables, and none should be learned.

Relative to that target-dependent reference, the outcomes distinguished in
this document are:

\begin{itemize}
  \item for a deterministic child: a rule that coincides with the mechanism;
  \item for a deterministic child: a sample-adequate but non-minimal rule;
  \item for a deterministic child: a defeasible representation that differs
  from the mechanism string;
  \item for a root or child: a rule that holds on the finite sample because a
  population counterexample is missing from that sample;
  \item for a root: an assumption construction that satisfies the selected
  learning semantics while leaving the target underdetermined by its
  predictors;
  \item search termination under the configured procedure, including timeout
  or \code{completed_no_solution}, which for a stochastic root target may be
  the intended outcome under the reference above.
\end{itemize}

These classes separate procedural exit status, finite-sample adequacy, and
mechanism alignment under the target-dependent reference.

\subsection{Scope}

The evidence comes from three small binary fixtures, fixed seed-42 samples,
and the learner configurations described below. Learning is target-wise: one
frozen table is held fixed, and each observed variable is selected in turn as
the learning target. Changing the target changes the positive and negative
examples and the background-knowledge encoding of the remaining columns; the
underlying rows remain the same sample.

Only the deterministic child has an evaluator-desired deterministic rule over
its observed parents. Root-target runs are diagnostics of the same pipeline
when the target itself is generated stochastically: they show how finite
support, learning semantics, and search budget shape the emitted theory or
search outcome when no underlying deterministic rule from the other variables
should be learned.

\subsection{Object of study}

The pipeline under study is target-wise ABA Learning over encoded tabular
data. For each target it receives background knowledge and labelled examples
only, and it emits an ABA framework of rules, assumptions, and contraries
under a selected learning semantics and search configuration.

The evidence recorded here therefore concerns learned rule structure, search
behaviour, and the relation of those outputs to the evaluator-only mechanism
reference for the fixture under study.

\subsection{ABA framework}

An ABA framework is a tuple
\[
\mathcal{F}=\langle\mathcal{L},\mathcal{R},\mathcal{A},
\overline{\cdot}\rangle,
\]
where \(\mathcal{L}\) is a language, \(\mathcal{R}\) is a set of rules,
\(\mathcal{A}\subseteq\mathcal{L}\) is a set of assumptions, and
\(\overline{\cdot}\) maps each assumption \(\alpha\in\mathcal{A}\) to its
contrary \(\overline{\alpha}\in\mathcal{L}\).

A rule has the form
\[
h\leftarrow b_1,\ldots,b_m.
\]
If \(m=0\), it is a fact. Write \(\Delta\vdash_{\mathcal{R}} s\) when a claim
\(s\in\mathcal{L}\) is derivable from a set of assumptions
\(\Delta\subseteq\mathcal{A}\) using the rules in \(\mathcal{R}\).

Attacks are generated by contraries: \(\Delta\) attacks an assumption
\(\alpha\in\mathcal{A}\) when \(\Delta\vdash_{\mathcal{R}}\overline{\alpha}\).
A set \(\Delta\subseteq\mathcal{A}\) is \emph{conflict-free} if it attacks none
of its own members. It is \emph{closed} if whenever
\(\Delta\vdash_{\mathcal{R}}\alpha\) for some \(\alpha\in\mathcal{A}\), then
\(\alpha\in\Delta\).

A set \(\Delta\subseteq\mathcal{A}\) is a \emph{stable extension} of
\(\mathcal{F}\) if it is closed, conflict-free, and attacks every assumption
in \(\mathcal{A}\setminus\Delta\). Write \(\operatorname{Stab}(\mathcal{F})\)
for the collection of all stable extensions of \(\mathcal{F}\).

A claim \(s\in\mathcal{L}\) is accepted with respect to a stable extension
\(\Delta\) if there exists \(\Delta'\subseteq\Delta\) such that
\(\Delta'\vdash_{\mathcal{R}} s\); write \(\mathcal{F}\models_{\Delta}s\) when
this holds. Write \(\mathcal{F}\models_{\mathrm{caut}}s\) when \(s\) is
accepted with respect to every stable extension of \(\mathcal{F}\). A learned
framework may therefore combine ordinary rules with explicit exceptional
conditions expressed by assumptions and contraries.

\subsection{ABA Learning task}

An ABA Learning task begins with background knowledge and two finite sets of
examples:
\[
\Epos=\{e^+_1,\ldots,e^+_p\},\qquad
\Eneg=\{e^-_1,\ldots,e^-_q\}.
\]
The learner applies symbolic transformations to construct a framework
\(\mathcal{F}'\) under which the examples satisfy the selected consequence
condition. The learned object is itself an ABA framework.

The transformations relevant here are:

\begin{itemize}
  \item \textbf{Rote learning.} Add example-specific rules from the positive
  examples.
  \item \textbf{Folding.} Replace example-specific conditions with reusable BK
  predicates, producing intensional rules.
  \item \textbf{Subsumption.} Remove a specialised rule when an appropriate more
  general rule already exists.
  \item \textbf{Assumption introduction.} Make an over-general rule defeasible by
  adding an assumption, then learn rules for its contrary to represent
  exceptions.
\end{itemize}

\subsection{Exact-value target-wise encoding}

In this investigation the learning task is instantiated from a tabular sample.
For each row identifier \(i\), every non-target variable is represented by
exactly one value predicate. When \(c\) is the target, for example, the BK
contains facts such as

\begin{lstlisting}
a_val_1(9).
b_val_0(9).
\end{lstlisting}

and row 9 contributes either \(c(9)\in\Epos\) or \(c(9)\in\Eneg\), according to
its target value. For a binary target \(Y\),
\[
\Epos_Y=\{Y(i):Y_i=1\},\qquad
\Eneg_Y=\{Y(i):Y_i=0\}.
\]
All non-target columns are available as BK predictors in their serialised
order. The encoding interface is the same for every target. The
evaluator-side desired object still depends on the target's generating role:
only a deterministic child has a desired parent mechanism rule.

\subsection{Brave and cautious learning}

Brave and cautious learning are the two consequence conditions under which a
learned framework \(\mathcal{F}'\) may be required to cover \(\Epos\) and
exclude \(\Eneg\).

Brave learning requires an existential witness: there must exist some
\(\Delta\in\operatorname{Stab}(\mathcal{F}')\) that simultaneously accepts
every positive example and rejects every negative example,
\[
\exists\Delta\in\operatorname{Stab}(\mathcal{F}')
\quad
\bigl[
  \forall e\in\Epos,\ \mathcal{F}'\models_\Delta e
  \ \land\
  \forall e\in\Eneg,\ \mathcal{F}'\not\models_\Delta e
\bigr].
\]

Cautious learning requires every positive example to be a cautious consequence
and every negative example to be excluded as a cautious consequence,
\[
\forall e\in\Epos,\ \mathcal{F}'\models_{\mathrm{caut}}e,
\qquad
\forall e\in\Eneg,\ \mathcal{F}'\not\models_{\mathrm{caut}}e.
\]

Thus the two modes quantify differently over \(\operatorname{Stab}(\mathcal{F}')\):
brave learning uses one witnessing extension, while cautious learning uses
acceptance in every stable extension.

\subsection{Greedy and non-deterministic folding}

Folding is controlled by \code{folding_mode}, together with companion options
for selection and folding space. The two modes used here are as follows.

\paragraph{\code{folding_mode(greedy)}.}
A rote rule is folded in one deterministic pass against matching background
predicates, under \code{folding_selection(mgr)} and
\code{folding_space(bk)}. This is the folding regime of the AAMAS
configuration.

\paragraph{\code{folding_mode(nd)}.}
Folding proceeds incrementally under a folding-token budget
(\code{folding_steps}), with \code{folding_selection(any)} and
\code{folding_space(all)}. This is the folding regime of the ECAI
configuration and of the cautious nd configurations used later.

Each published configuration also sets learning semantics and
\code{asm_intro}. When two named configurations are compared as wholes, several
options change together.

\subsection{Assumption introduction: \code{relto} and \code{sechk}}

Assumption introduction is the transformation that makes an over-general
folded rule defeasible by placing an assumption in its body and learning
rules for the contrary of that assumption. In \ABALearn{} it is controlled by
the option \code{asm_intro}, which takes one of two values: \code{relto} or
\code{sechk}. Both are used after a folded candidate fails the configured
post-folding entailment check. They differ in how the first assumption-repair
step is chosen.

\paragraph{\code{asm_intro(relto)}.}
The learner first searches the current framework for an existing assumption
that is relative to the body of the folded rule under consideration. If such
an assumption is found, it is reused in the repaired rule. If none is found,
the learner may generate a new assumption and continue along the subsequent
generalisation path.

\paragraph{\code{asm_intro(sechk)}.}
The learner first generates a new provisional assumption for the folded rule
and then subjects the resulting framework to the semantic-checking branch of
generalisation (\code{gen5}/\code{gen6}), which inspects stable-extension
consequences before deciding how the assumption is retained or revised.

\section{Causal fixtures and evaluator ground truth}

This section records the generating processes, population certificates,
evaluator-only mechanism references, and frozen samples used by the probes
below. Mathematical labels are \(A,B,C,D\); learner-safe identifiers are
\code{a},\code{b},\code{c},\code{d}. In emitted Prolog rules the capital
argument (for example the \code{A} in \code{c(A)}) is the row identifier, not
the causal variable \(A\).

\subsection{Principal fixture: binary AND collider (H0)}

The principal fixture is the unshielded collider
\[
G_0:\qquad A\longrightarrow C\longleftarrow B
\]
with no \(A\)--\(B\) edge. The roots are mutually independent,
\[
A\sim\operatorname{Bernoulli}(4/5),
\qquad
B\sim\operatorname{Bernoulli}(7/10),
\qquad
A\indep B,
\]
and the child is the deterministic AND mechanism
\[
C=A\land B.
\]

Causal sufficiency is declared by fixture design: the root exogenous noise
terms are mutually independent and there is no omitted common cause. The
causal Markov condition holds by construction of the joint,
\[
P^\ast(a,b,c)=P^\ast(a)P^\ast(b)P^\ast(c\mid a,b).
\]
Ordinary faithfulness was verified exactly by auditing every singleton-pair
conditional-independence query against \(d\)-separation. The sole population
independence is \(A\indep B\); conditioning on the collider yields
\(A\notindep B\mid C\), and each parent is dependent on \(C\).

Under ordinary conditional-independence semantics, the skeleton is \(A-C-B\)
and the unshielded collider \(A\rightarrow C\leftarrow B\) is oriented in the
CPDAG; the corresponding MEC contains only \(G_0\). This is the ordinary
CI-based reading. Deterministic mechanisms can impose additional functional
constraints beyond ordinary CI; no extended recovery object is asserted here.
The graph, certificates, and mechanism reference are evaluator-only and are
withheld from \ABALearn{}.

\subsection{Evaluator-only mechanism reference}

For the deterministic child \(C\), the canonical positive-state exact-value
rule is

\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A).
\end{lstlisting}

On this fixture the formal truth-table rule, the population-supported rule,
and the rule supported by the frozen sample coincide on that string. That
string is the evaluator reference against which learned theories for target
\code{c} are compared. Comparison uses rule bodies, assumptions, contraries,
and the target's generating role together: a mechanism-aligned string is one
form of evidence; an assumption-rich but sample-adequate theory is another
object under the same reference.

The roots \(A\) and \(B\) are generated by independent stochastic mechanisms
\(A\sim\operatorname{Bernoulli}(4/5)\) and \(B\sim\operatorname{Bernoulli}(7/10)\).
Neither root is a deterministic function of the other observed variables, so
when \code{a} or \code{b} is the learning target no underlying deterministic
rule from those predictors should be learned.

\(D\sim\operatorname{Bernoulli}(1/2)\) with no edges. Variable order places
\code{d} last, so for target \code{c} the exact-value BK predictors appear as
\([a,b,d]\): the distractor is trailing. The evaluator rule for \code{c}
remains

\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A).
\end{lstlisting}

The variables \(A\), \(B\), and the isolated \(D\) are each generated
stochastically. When any of them is the learning target, there is no
underlying deterministic rule from the remaining observed variables that
should be learned. The frozen table used below is again an IID sample with
\(n=30\) and seed~42 on this four-variable process.

\paragraph{BK-leading isolated \(A\) (H3).}
This fixture uses independent roots
\[
A\sim\operatorname{Bernoulli}(1/2),\qquad
B\sim\operatorname{Bernoulli}(4/5),\qquad
D\sim\operatorname{Bernoulli}(7/10),
\]
with \(A\) isolated (no edges) and deterministic child \(C=B\land D\). Variable
order places \code{a} first, so for target \code{c} the BK predictors appear as
\([a,b,d]\): the distractor is leading. The evaluator rule for \code{c} is

\begin{lstlisting}
c(A) :- b_val_1(A), d_val_1(A).
\end{lstlisting}

The isolated variable \(A\) and the roots \(B\) and \(D\) are each generated
stochastically. When any of them is the learning target, there is no
underlying deterministic rule from the remaining observed variables that
should be learned. The frozen table used below is an IID sample with \(n=30\)
and seed~42 on this process.

Both extensions have verified Markov factorisation and exact ordinary
faithfulness certificates. As with the principal fixture, the generating
graph, certificates, and mechanism references are withheld from the learner.

\subsection{Strength of comparisons}

Each probe is read at one of three attribution strengths.

\begin{itemize}
  \item \textbf{Exact paired option ablation.}
  Fixture, sample, encoding, and the remaining learner options are held fixed;
  one learning option changes.
  Probes H4 and H4b change \code{learning_mode} under otherwise fixed nd /
  \code{relto} settings;
  H5 changes \code{learning_mode} under the fixed Greedy / \code{mgr} / BK /
  \code{relto} bundle;
  H6a changes \code{folding_steps};
  H7a and H7b change only \code{asm_intro}.
  \item \textbf{Controlled data or fixture intervention.}
  The learner configuration is held fixed (or compared only within one arm);
  one designed property of the sample or fixture changes.
  H1 uses a nested seed-42 prefix \(n=25\) of the principal table under AAMAS;
  H2 adds a trailing isolated \(D\) under AAMAS;
  H3 uses the BK-leading isolated-\(A\) fixture under ECAI (with AAMAS as
  secondary);
  H6b varies nested sample size \(n\in\{30,60,90\}\) at fixed
  \code{folding_steps(2)} under \code{baseline_cautious}.
  \item \textbf{Bundle-level contrast.}
  Several learner settings change together, so a behavioural difference is
  attributed to the configuration bundle rather than to one option.
  H0 compares \code{aamas2025} with \code{ecai2024} on the principal table.
  Where both exist, contrasts between \code{greedy_cautious} and
  \code{baseline_cautious} are likewise bundle-level (Greedy versus nd), as
  used secondarily in H5.
\end{itemize}

The strength level states how far a difference among outcomes, deltas, or
traces can be attributed to the designed intervention of that probe.

\subsubsection*{Child target \code{c}}

\observation
Under AAMAS, every positive example for \code{c} has \((A,B)=(1,1)\). Greedy
folding with BK space therefore builds the single maximal co-occurrence body
\(\{\mathtt{a\_val\_1},\mathtt{b\_val\_1}\}\). After mgr deduplication the
emitted delta is

\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A).
\end{lstlisting}

Brave entailment succeeds immediately: no negative example shares that body,
so no assumption is introduced. The string coincides with the evaluator
mechanism reference for \(C\).

Under ECAI, nd folding takes one BK predicate at a time. From an early
positive, the first fold replaces the example identifier by
\code{a_val_1}, the first predictor in BK order, yielding the unary rule
\code{c(A) :- a_val_1(A)}. That body also holds of every negative with
\(A=1,B=0\). Assumption introduction produces

\begin{lstlisting}
c(A) :- alpha_1(A), a_val_1(A).
c_alpha_1(A) :- b_val_0(A).
assumption(alpha_1(A)).
contrary(alpha_1(A),c_alpha_1(A)) :- assumption(alpha_1(A)).
\end{lstlisting}

\explanation
The ECAI theory is sample-adequate under brave checking: \(c\) is derived when
\(a=1\), unless the assumption is attacked when \(b=0\). Across the target rule
and the contrary it cites both parents of \(C\). Its ABA shape is nevertheless
different from the AAMAS conjunction: the first fold latched onto the leading
BK predictor, and the second parent enters only through contrary learning.

\subsubsection*{Root targets \code{a} and \code{b}}

\observation
For target \code{a}, positives fall into two predictor cells,
\((B,C)=(1,1)\) and \((B,C)=(0,0)\). The cell \((B,C)=(0,0)\) also contains
negatives: row~9 is positive with joint values \((1,0,0)\), while rows~26 and~30
are negative with \((0,0,0)\), yet all share the BK literals \code{b_val_0} and
\code{c_val_0}. Target \code{b} is the symmetric case with the roles of \(A\)
and \(B\) swapped.

Under AAMAS, greedy folding proposes the two Horn candidates

\begin{lstlisting}
a(A) :- b_val_1(A), c_val_1(A).
a(A) :- b_val_0(A), c_val_0(A).
\end{lstlisting}

The both-one rule is accepted. The both-zero rule covers the negative rows~26
and~30, so brave entailment fails. The learner introduces an assumption on that
body; contrary rote learning then cites those negatives, and greedy folding of
the contrary reconstructs the same both-zero body. Under \code{asm_intro(relto)}
a further relative assumption cannot be added for that body, the engine reports
KO, and the cell ends as \code{completed_no_solution} with no emitted delta.
Target \code{b} mirrors this path.

Under ECAI, nd folding again proceeds one predicate at a time. The learner
first builds a safe block for the both-one positives,
\begin{lstlisting}
a(A) :- alpha_1(A), b_val_1(A).
c_alpha_1(A) :- c_val_0(A).
\end{lstlisting}
That block covers positives with \((B,C)=(1,1)\) and excludes negatives with
\(B=1\) and \(C=0\). The both-zero positives remain uncovered, so a second
ordinary target rule is still required.

Folding an early both-zero positive (row~8) produces the candidate
\code{a(A) :- b_val_0(A)}. Brave entailment fails on that candidate. The same
BK literals also hold of the negative examples in rows~26 and~30. The learner
therefore introduces an assumption \(\alpha_2\) on the body, giving
\code{a(A) :- alpha_2(A), b_val_0(A)}. Contrary rote learning cites rows~26
and~30 as grounds for \(\mathtt{c\_alpha\_2}\).

Folding that contrary first tries \code{b_val_0}. Under \code{relto} this
returns KO against the already present \(\alpha_2\). The next fold tries
\code{c_val_0}, yielding \code{c_alpha_2(A) :- c_val_0(A)}. Even that unary
contrary remains too strong for the joint example set. The learner therefore
introduces a further assumption \(\alpha_3\) on the contrary. Rote learning of
\(\mathtt{c\_alpha\_3}\) then cites the both-zero positives, including
row~9. Folding that contrary re-uses \(\alpha_2\) together with
\code{b_val_0}. The trace records this close as
\code{found: alpha_2/1 ... OK}. The final delta for target \code{a} is

\begin{lstlisting}
a(A) :- alpha_1(A), b_val_1(A).
a(A) :- alpha_2(A), b_val_0(A).
c_alpha_1(A) :- c_val_0(A).
c_alpha_2(A) :- alpha_3(A), c_val_0(A).
c_alpha_3(A) :- alpha_2(A), b_val_0(A).
assumption(alpha_1(A)).
assumption(alpha_2(A)).
assumption(alpha_3(A)).
contrary(alpha_1(A),c_alpha_1(A)) :- assumption(alpha_1(A)).
contrary(alpha_2(A),c_alpha_2(A)) :- assumption(alpha_2(A)).
contrary(alpha_3(A),c_alpha_3(A)) :- assumption(alpha_3(A)).
\end{lstlisting}

Target \code{b} is the mirror obtained by swapping the roles of \(A\) and
\(B\).

\explanation
The decisive geometry is the predictor cell \((B,C)=(0,0)\). Row~9 is a
positive example for target \code{a}. Its joint values are
\((A,B,C)=(1,0,0)\). Row~26 is a negative example. Its joint values are
\((0,0,0)\). Both rows carry the BK facts \code{b_val_0} and \code{c_val_0}.
Any Horn rule that uses only those predictors therefore treats the two rows
alike. It would derive \code{a} at both identifiers, or at neither.

The emitted \(\alpha_2/\alpha_3\) nest works because assumptions are
grounded per row identifier. At a fixed row \(i\), the relevant instances are
\(\alpha_2(i)\) and \(\alpha_3(i)\), with contraries
\(\mathtt{c\_alpha\_2}(i)\) and \(\mathtt{c\_alpha\_3}(i)\). The local rules
are
\begin{lstlisting}
a(i) :- alpha_2(i), b_val_0(i).
c_alpha_2(i) :- alpha_3(i), c_val_0(i).
c_alpha_3(i) :- alpha_2(i), b_val_0(i).
\end{lstlisting}
On every both-zero row, both \code{b_val_0(i)} and \code{c_val_0(i)} hold.
Accepting \(\alpha_2(i)\) therefore derives \(\mathtt{c\_alpha\_3}(i)\) and
attacks \(\alpha_3(i)\). Accepting \(\alpha_3(i)\) derives
\(\mathtt{c\_alpha\_2}(i)\) and attacks \(\alpha_2(i)\). The two assumptions
cannot both be accepted at the same row.

This leaves two locally stable choices at each both-zero identifier. If
\(\alpha_2(i)\) is accepted and \(\alpha_3(i)\) is rejected, then
\code{a(i)} is derived. If \(\alpha_3(i)\) is accepted and \(\alpha_2(i)\) is
rejected, then \code{a(i)} is blocked.

Brave learning asks for one witnessing stable extension \(\Delta\) of the
whole grounded framework. That extension must cover every positive example and
exclude every negative example at once. Such a witness exists. On row~9 it
accepts \(\alpha_2(9)\) and rejects \(\alpha_3(9)\). The rule
\code{a(9) :- alpha_2(9), b_val_0(9)} then derives the positive example
\((1,0,0)\). On row~26 it accepts \(\alpha_3(26)\) and rejects
\(\alpha_2(26)\). The same BK facts are present, but without \(\alpha_2(26)\)
the rule for \code{a} does not fire, so the negative example \((0,0,0)\) is
excluded. The two rows are therefore separated by their ground assumption
atoms, even though their BK predictors are identical.

\begin{center}
\small
\begin{tabular}{@{}llll@{}}
\toprule
Row & Joint \((A,B,C)\) & Choice in \(\Delta\) & Effect \\
\midrule
9 & \((1,0,0)\) (positive) &
\(\alpha_2(9)\) in, \(\alpha_3(9)\) out &
\code{a(9)} derived \\
26 & \((0,0,0)\) (negative) &
\(\alpha_2(26)\) out, \(\alpha_3(26)\) in &
\code{a(26)} blocked \\
\bottomrule
\end{tabular}
\end{center}

Other stable extensions may reverse those local choices. Brave entailment
requires only that at least one joint witness exists. The framework therefore
passes brave checking on the finite sample.

For this mechanism, target \code{a} should have no learned solution:
\(A\) is generated stochastically, and there is no underlying deterministic
rule from the other observed variables. A solution was nevertheless found.
Brave entailment permits one stable extension to assign opposite statuses to
the ground assumptions \(\alpha_2(i)\) and \(\alpha_3(i)\) at different row
identifiers. That per-row split covers the positive example \((1,0,0)\) and
excludes the negative example \((0,0,0)\) even though the two rows share the
same BK predictors. The ECAI \code{solved} outcome records that brave
covering. It does not record recovery of a deterministic rule for \(A\).

\boundary
H0 is the establishing bundle contrast on one complete-support table. Procedural
\code{solved} covers both the AAMAS mechanism-string match for \code{c} and the
ECAI assumption-rich theories for \code{c} and the roots. Attribution of the
arm difference is to the full AAMAS versus ECAI option bundle.

\subsection{H2: trailing isolated covariate under Greedy}

\question
On the principal AND collider extended by an independent isolated root \(D\),
does AAMAS learning of the deterministic child \code{c} retain irrelevant
\code{d} literals, or does it return the evaluator \(D\)-free rule
\code{c(A) :- a_val_1(A), b_val_1(A).}?

\comparison
The H0 collider, root laws, and mechanism \(C=A\land B\) are preserved. An
isolated root \(D\sim\operatorname{Bernoulli}(1/2)\) is added with no edges.
Variable order places \code{d} last, so for target \code{c} the BK predictors
are \([a,b,d]\). The run uses AAMAS on the frozen \(n=30\) seed-42 sample.
Among the eighteen positive \code{c} rows, both \(D=1\) and \(D=0\) occur nine
times.

\observation
AAMAS solves target \code{c} and emits
\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A), d_val_1(A).
c(A) :- a_val_1(A), b_val_1(A), d_val_0(A).
\end{lstlisting}
Irrelevant \(D\) is retained. The two rules are sample-adequate and jointly
cover the observed values of \(D\), but they are non-minimal relative to the
evaluator mechanism
\begin{lstlisting}
c(A) :- a_val_1(A), b_val_1(A).
\end{lstlisting}
On the three-variable H0 table without \(D\), the same AAMAS bundle emitted
exactly that \(D\)-free string.

\explanation
Under greedy folding with \code{folding_space(bk)}, each positive example is
folded into a maximal co-occurrence body from the BK literals that hold of that
row. A positive with \(D=1\) therefore keeps \code{d_val_1}. A positive with
\(D=0\) keeps \code{d_val_0}. The trace shows this explicitly: after
\code{a_val_1} and \code{b_val_1}, the next fold attaches the matching
\code{d_val_*} literal. Mgr selection then keeps the resulting bodies. There
is no later step that merges the complementary pair by deleting the
\code{d} literal. The failure mode under test is therefore distractor
retention on a solved child, not failure to solve \code{c}.

\boundary
H2 is a controlled fixture intervention under fixed AAMAS settings. The
primary signal is the balanced \(n=30\) distractor split on target \code{c}.

\subsection{H3: BK-leading isolated covariate under nd}

\question
On a BD AND collider with an isolated root placed first in BK order, does ECAI
learning of the deterministic child \code{c} select that isolated variable in
the first fold and retain it in the final theory, or does it return the
evaluator rule \code{c(A) :- b_val_1(A), d_val_1(A).}?

\comparison
The fixture is \(B\rightarrow C\leftarrow D\) with \(C=B\land D\) and an
independent isolated root \(A\sim\operatorname{Bernoulli}(1/2)\). Variable
order places \code{a} first, so for target \code{c} the BK predictors are
\([a,b,d]\). The primary run is ECAI brave nd on the frozen \(n=30\) seed-42
sample. An AAMAS run on the same table supplies a bundle-level contrast.
Among the fifteen positive \code{c} rows, every row has \((B,D)=(1,1)\), while
both values of \(A\) occur.

\observation
The ECAI trace opens with the first fold
\begin{lstlisting}
folding result: c(A) <- [a_val_1(A)]
\end{lstlisting}
Assumption introduction follows immediately. The full emitted delta for
target \code{c} is:
\begin{lstlisting}
c(A) :- alpha_1(A), a_val_1(A).
c(A) :- alpha_2(A), a_val_0(A).
c_alpha_1(A) :- b_val_0(A).
c_alpha_1(A) :- alpha_3(A), b_val_1(A).
c_alpha_2(A) :- d_val_0(A).
c_alpha_2(A) :- b_val_0(A).
c_alpha_3(A) :- alpha_1(A), a_val_1(A).
assumption(alpha_1(A)).
assumption(alpha_2(A)).
assumption(alpha_3(A)).
contrary(alpha_1(A),c_alpha_1(A)) :- assumption(alpha_1(A)).
contrary(alpha_2(A),c_alpha_2(A)) :- assumption(alpha_2(A)).
contrary(alpha_3(A),c_alpha_3(A)) :- assumption(alpha_3(A)).
\end{lstlisting}
The two ordinary target rules are gated only on the isolated variable \(A\).
Mechanism parents enter through the contrary layer: \(\mathtt{c\_alpha\_1}\)
and \(\mathtt{c\_alpha\_2}\) cite \(b\) and \(d\), with a further nested
assumption \(\alpha_3\) under the \(a{=}1\) branch. The theory is therefore
organised around \(A\), with \(B\) and \(D\) used to repair that scaffolding.
It does not match the evaluator BD AND \code{c(A) :- b_val_1(A), d_val_1(A).}.

On the same sample, AAMAS also solves \code{c} while retaining \code{a}:
\begin{lstlisting}

c(A) :- a_val_0(A), b_val_1(A), d_val_1(A).
\end{lstlisting}

\explanation
Under nd folding with \code{any} selection, the first admissible BK predicate
becomes the first generalising fold. Here that predicate is an \code{a}-value
literal, because \code{a} leads the serialised BK. The unary fold
over-generalises, so the learner introduces \(\alpha_1\) (then \(\alpha_2\))
and learns contraries around those \(A\)-gated rules. Later folds place \(b\)
and \(d\) in \(\mathtt{c\_alpha\_1}\) and \(\mathtt{c\_alpha\_2}\), but the
ordinary target rules keep the initial \(a\)-gates. The AAMAS contrast reaches
distractor retention by a different route: greedy maximal co-occurrence keeps
every matching literal, including leading \code{a}, and splits the AND across
the two values of \(A\).

In both cases the child is solved, and in both cases the isolated leading
variable is retained. The failure mode is distractor inclusion driven by BK
order, not failure to solve \code{c}.

\paragraph{Contrary-structure divergence under the two \(A\) gates.}
The ECAI delta is asymmetric under the two leading-\(a\) gates. That
asymmetry is part of the H3 theory and deserves a separate reading.

Under \(a{=}1\) (\(\alpha_1\)), the contrary of \(\alpha_1\) is
\emph{nested}:
\begin{lstlisting}
c_alpha_1(A) :- b_val_0(A).
c_alpha_1(A) :- alpha_3(A), b_val_1(A).
c_alpha_3(A) :- alpha_1(A), a_val_1(A).
\end{lstlisting}
Under \(a{=}0\) (\(\alpha_2\)), the contrary of \(\alpha_2\) is
\emph{flat} and cites the mechanism parents directly:
\begin{lstlisting}
c_alpha_2(A) :- d_val_0(A).
c_alpha_2(A) :- b_val_0(A).
\end{lstlisting}
So one gate is repaired by a further assumption \(\alpha_3\), while the other
is repaired by ordinary \(b\)/\(d\) literals alone.

The divergence is a search-order effect under nd folding with \code{any}
selection, \(b\)-before-\(d\) BK order after leading \code{a}, cover-and-repair,
and \code{asm_intro(relto)}. It is not a difference in the underlying mechanism
of \(C\), and it is not caused by the brave/cautious learning-mode choice ---
the same \(\alpha_1\)-nested / \(\alpha_2\)-flat skeleton appears under both
H3 brave and H4b cautious. Concretely:

\begin{enumerate}
  \item Contrary repair for \(\mathtt{c\_alpha\_1}\) occurs first, because the
  first positive example has \(a{=}1\).
  \item Under that gate, the first contrary seed has \((b,d)=(0,1)\), so search
  commits to \code{b_val_0}. The remaining contrary residuals have
  \((b,d)=(1,0)\).
  \item Folding those residuals with \code{b_val_1} over-generalises. Instead
  of backtracking to a flat cover \(\{\code{b_val_0},\code{d_val_0}\}\),
  cover-and-repair introduces \(\alpha_3\) on the \code{b_val_1} body.
  \item When search later repairs \(\mathtt{c\_alpha\_2}\) under \(a{=}0\), a
  fold that would reuse \code{b_val_1} meets the already declared
  \(\alpha_3\) under \code{relto} and is rejected. Search then falls through
  to \code{d_val_0} and \code{b_val_0}, yielding the flat contrary.
\end{enumerate}

Thus the nested \(\alpha_1\) side and the flat \(\alpha_2\) side are two
stages of one sequential repair path. The second gate inherits the assumption
minted while repairing the first.

\(\alpha_1\)-nested versus \(\alpha_2\)-flat contrary split is a secondary
procedural feature of that same theory.

\subsection{H4: brave versus cautious under nd}

\subsubsection{H4: roots on the H0 table}

\question
On the principal AND-collider table of H0, does changing
\code{learning_mode(brave)} to \code{learning_mode(cautious)} alter the
outcomes for root targets \code{a} and \code{b} that, under

separating rows~9 and~26, and what happens to control target \code{c}?

\comparison
The H0 fixture, frozen \(n=30\) seed-42 table, target-specific examples, and
BK were held fixed. The two learner configurations compared are
\code{ecai2024} and \code{baseline_cautious}. Both use nd folding with
\code{folding_selection(any)}, \code{folding_space(all)},
\code{asm_intro(relto)}, and \code{folding_steps(10)}. They differ in
learning mode: \code{ecai2024} sets \code{learning_mode(brave)};
\code{baseline_cautious} sets \code{learning_mode(cautious)}. The locked
\code{ecai2024} outputs are the brave comparator.

\begin{center}
\begin{tabular}{@{}lcc@{}}
\toprule
Target & \code{ecai2024} & \code{baseline_cautious} \\
\midrule
\(a\) & \code{solved} & \code{completed_no_solution} \\
\(b\) & \code{solved} & \code{completed_no_solution} \\
\(c\) & \code{solved} & \code{solved}, byte-identical delta \\

\end{tabular}
\end{center}

\observation
For target \code{a}, the \code{ecai2024} and \code{baseline_cautious} traces
coincide through the early \(\alpha_1,\alpha_2,\alpha_3\) construction from
H0. They diverge at one assumption-introduction step. After
\begin{lstlisting}
folding result: c_alpha_3(A) <- [b_val_0(A)]
\end{lstlisting}
the learner proposes to re-use the already declared assumption \(\alpha_2\)
in that body:
\begin{lstlisting}
c_alpha_3(A) :- alpha_2(A), b_val_0(A).
\end{lstlisting}
Under \code{ecai2024} the proposal is accepted; under
\code{baseline_cautious} it is rejected:

\begin{lstlisting}
% ecai2024:
 found: alpha_2/1 ... OK, assumption introduction result:
   c_alpha_3(A) <- [alpha_2(A),b_val_0(A)]

% baseline_cautious:
 found: alpha_2/1 ... KO, cannot introduce an assumption for [b_val_0(A)]
\end{lstlisting}

Under \code{ecai2024}, that OK closes the both-zero nest from H0 and the
learner writes a solution. Under \code{baseline_cautious}, the KO is followed
by further failed folds, exhaustion of \code{folding_steps(10)}, and
\code{completed_no_solution} with no emitted delta. Target \code{b} exhibits
the same divergence with the roles of \(A\) and \(B\) swapped.

Under \code{baseline_cautious}, control target \code{c} remains
\code{solved}. Its delta is byte-identical to the locked \code{ecai2024}
delta for \code{c}:
\begin{lstlisting}
c(A) :- alpha_1(A), a_val_1(A).
c_alpha_1(A) :- b_val_0(A).
assumption(alpha_1(A)).
contrary(alpha_1(A),c_alpha_1(A)) :- assumption(alpha_1(A)).
\end{lstlisting}
Thus \code{learning_mode(cautious)} still admits an assumption-bearing theory
for the child on this table, while rejecting the residual \(\alpha_2\) reuse
for the roots.

\explanation
Under both configurations the search builds toward the same both-zero nest:
\begin{lstlisting}
a(A) :- alpha_2(A), b_val_0(A).
c_alpha_2(A) :- alpha_3(A), c_val_0(A).
c_alpha_3(A) :- alpha_2(A), b_val_0(A).
\end{lstlisting}
Write \(\mathcal{F}_{\mathrm{nest}}\) for a framework containing this nest.
The decisive conflict is observational. Row~9 contributes
\(a(9)\in\Epos\) with joint values \((A,B,C)=(1,0,0)\). Row~26 contributes
\(a(26)\in\Eneg\) with joint values \((0,0,0)\). Relative to BK the two rows
are indistinguishable: both carry \code{b_val_0} and \code{c_val_0}. No Horn
body over those predictors alone can accept one row and reject the other.

The nest does not separate the rows by BK. It separates them by ground
assumption membership. At any both-zero row identifier \(i\), the assumptions
\(\alpha_2(i)\) and \(\alpha_3(i)\) attack each other through the contrary
layer, so a stable extension can take only one of the two local choices:
\begin{center}
\small
\begin{tabular}{@{}lll@{}}
\toprule
Choice at row \(i\) & Acceptance of \(a(i)\) & Derived contrary \\
\midrule
\(\alpha_2(i)\in\Delta\), \(\alpha_3(i)\notin\Delta\) &
\(\mathcal{F}_{\mathrm{nest}}\models_{\Delta}a(i)\) &
\(\mathtt{c\_alpha\_3}(i)\) \\
\(\alpha_2(i)\notin\Delta\), \(\alpha_3(i)\in\Delta\) &
\(\mathcal{F}_{\mathrm{nest}}\not\models_{\Delta}a(i)\) &
\(\mathtt{c\_alpha\_2}(i)\) \\
\bottomrule
\end{tabular}
\end{center}

\paragraph{Brave entailment.}
Under \code{learning_mode(brave)}, a learned framework \(\mathcal{F}'\) is
accepted when there exists one witnessing stable extension covering the
examples:
\[
\exists\Delta\in\operatorname{Stab}(\mathcal{F}')
\;\bigl[
\forall e\in\Epos,\ \mathcal{F}'\models_{\Delta}e
\;\land\;
\forall e\in\Eneg,\ \mathcal{F}'\not\models_{\Delta}e
\bigr].
\]
For \(\mathcal{F}_{\mathrm{nest}}\) such a witness exists. On row~9 it chooses
\(\alpha_2(9)\) in and \(\alpha_3(9)\) out, so
\begin{lstlisting}
a(9) :- alpha_2(9), b_val_0(9)
\end{lstlisting}
yields \(\mathcal{F}_{\mathrm{nest}}\models_{\Delta}a(9)\). On row~26 it
chooses \(\alpha_2(26)\) out and \(\alpha_3(26)\) in, so
\(\mathcal{F}_{\mathrm{nest}}\not\models_{\Delta}a(26)\). The closing rule
\begin{lstlisting}
c_alpha_3(A) :- alpha_2(A), b_val_0(A).
\end{lstlisting}
is part of making those local choices coherent: whenever \(\alpha_2(i)\) is
accepted, \(\mathtt{c\_alpha\_3}(i)\) is derived and attacks \(\alpha_3(i)\).

Thus \(\mathcal{F}_{\mathrm{nest}}\) passes brave entailment because coverage
may depend on different ground assumption choices at different row identifiers
inside a single witness. The assumption-introduction check that proposes
re-using \(\alpha_2\) on \code{c_alpha_3(A) <- [b_val_0(A)]} therefore returns
OK, and \code{ecai2024} finishes with \code{solved}.

\paragraph{Failure under cautious entailment.}
Under \code{learning_mode(cautious)}, the same framework must satisfy the
stronger condition
\[
\forall e\in\Epos,\ \mathcal{F}'\models_{\mathrm{caut}}e,
\qquad
\forall e\in\Eneg,\ \mathcal{F}'\not\models_{\mathrm{caut}}e,
\]
where \(\mathcal{F}'\models_{\mathrm{caut}}s\) means that \(s\) is accepted
with respect to every stable extension of \(\mathcal{F}'\).

Apply that test to \(\mathcal{F}_{\mathrm{nest}}\) at row~9. The choice that
covers the positive is \(\alpha_2(9)\in\Delta\). The opposite choice,
\(\alpha_3(9)\in\Delta\) and \(\alpha_2(9)\notin\Delta\), also belongs to
\(\operatorname{Stab}(\mathcal{F}_{\mathrm{nest}})\). In any extension
\(\Delta'\) that takes the opposite choice,
\(\mathcal{F}_{\mathrm{nest}}\not\models_{\Delta'}a(9)\). Therefore
\(a(9)\) fails \(\mathcal{F}_{\mathrm{nest}}\models_{\mathrm{caut}}a(9)\):
it is not a cautious consequence. The brave cover of the positive exists, but
it is only an existential cover. Cautious entailment requires universal cover,
and this nest cannot provide it on an underdetermined BK cell.

That is why, under \code{baseline_cautious}, the same proposal returns
\begin{lstlisting}
found: alpha_2/1 ... KO, cannot introduce an assumption for [b_val_0(A)]
\end{lstlisting}
The learner never accepts the clause that would close the brave construction.
Search then exhausts \code{folding_steps(10)} and returns
\code{completed_no_solution}.

In short: \code{ecai2024} succeeds because brave entailment needs only some
stable extension that assigns opposite \(\alpha_2/\alpha_3\) statuses to
rows~9 and~26; \code{baseline_cautious} fails because \(a(9)\) is not accepted
in every stable extension of that same nest, so the residual \(\alpha_2\) reuse
cannot pass the cautious entailment check.

The control on target \code{c} is consistent with these semantics. Its
contrary folds to the ordinary body \code{b_val_0}, which does not require
opposite assumption membership across rows that share the same BK literals.
The cautious entailment checks therefore succeed, and the emitted delta
matches the \code{ecai2024} delta for \code{c}.

\boundary
H4 compares learner configurations \code{ecai2024} and
\code{baseline_cautious} on the locked H0 table, with matched nd folding
options, matched \code{asm_intro(relto)}, and \code{folding_steps(10)}. Root
\code{completed_no_solution} under \code{baseline_cautious} is the absence of
an accepted covering theory in that setting.

Target \(b\) mirrors this. Target \(c\) solves at every ceiling within
\code{tokens(1)}, with the same 134-line trace, approximately 1.3-second
runtime, and byte-identical delta.

\observation
For the no-solution roots, trace length and runtime grow approximately
linearly with \(M\) across the tested values. Each permitted token band adds
about nine new assumptions and roughly 500 trace lines without producing a
different accepted theory.

\explanation
\code{folding_steps(M)} acts as a token-budget ceiling, not as a literal count
of successful folds. The decisive root KO already occurs in the first band.
When budget remains, the nd controller increments the token allowance and
replays essentially the same failed assumption-introduction motif:
\[
\operatorname{lines}(M)
\approx C_{\mathrm{fixed}}+M\,C_{\mathrm{failed\ band}}.
\]
Through \(M=10\), the additional budget buys repeated failed search rather
than a new explanation.

\boundary
The experiment does not show that \(M=1\) is always sufficient. Other
learnable tasks may require more tokens. It explains the tested root cost but
does not yet provide a general stopping rule.

Within each pair, H0 or H3 fixture, \(n=30\) sample, target, examples, BK,

\(b\). Byte-identical H0/H3 \code{sechk} root deltas consequently reflect a
shared learner template, not a shared causal role.

\boundary
H7a does not establish that \code{sechk} is worse than \code{relto}, or that
first-BK closure is universal. It records a bounded brave-nd interaction on
seven exact input-matched pairs.
