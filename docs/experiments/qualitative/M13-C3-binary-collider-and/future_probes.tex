\section{Probe family H1 --- support sensitivity on AAMAS root targets}

Status: approved / not yet implemented / not tested / not a claim.

\subsection*{H1a --- spurious root rule under missing negative witness}
On this fixture, AAMAS, target \(a\) (symmetrically \(b\)), seed~42: if the
table is a nested prefix that omits all \((0,0,0)\) rows (e.g.\ \(n{=}25\)),
learning is predicted to \emph{solve} with a delta that includes
\[
\texttt{a(A) :- b\_val\_0(A), c\_val\_0(A).}
\]
(resp.\ \(\texttt{b(A) :- a\_val\_0(A), c\_val\_0(A).}\)), which is false as a
population implication and is blocked on approved \(n{=}30\) by \(E^-\) rows~26
and~30.

Nested-prefix fact: rows~1--25 of the approved sample contain no \((0,0,0)\)
atom; rows~26 and~30 are the only such observations in \(n{=}30\).

\subsection*{H1b --- negative witness in the unsafe cell}
If the sample contains at least one opposite-label row in that both-0 predictor
cell, the both-0 rule fails brave entailment under the observed AAMAS path. On
approved \(n{=}30\) this manifested as \texttt{completed\_no\_solution}, not as
emission of only the safe both-1 rule.

\subsection*{Explicit non-claims for H1}
\begin{itemize}
  \item Full support does not imply AAMAS will emit a ``correct'' deterministic
    root mechanism rule: roots have
    \texttt{no\_observed\_parent\_deterministic\_rule}.
  \item ``One of each population atom'' is a sufficient practical condition
    here; the operational point is a \emph{label conflict inside the greedy
    candidate body cell}.
\end{itemize}

\section{Probe family H2 --- irrelevant isolated covariate on AAMAS target \(c\)}

Status: design approved / not yet implemented / not tested / not a claim.
Requires a new schema-2 fixture before any learning run.

\subsection*{H2a --- irrelevant covariate enters greedy bodies}
Extend the AND collider with an isolated binary root
\(D\sim\mathrm{Bernoulli}(1/2)\), independent of \(\{A,B,C\}\).
Under AAMAS, when both values of \(D\) appear among \(E^+\) for \(c\), greedy
catalogue bodies are predicted to include a \texttt{d\_val\_*} literal; the
learner is \emph{not} expected to return the \(D\)-free evaluator-form rule
\[
\texttt{c(A) :- a\_val\_1(A), b\_val\_1(A).}
\]
even if an equivalent covering theory exists.

\subsection*{H2b --- learnability vs minimality}
On that extension, AAMAS target \(c\) \emph{may still solve}
(e.g.\ two \(D\)-conditioned rules for \(d{=}0\) and \(d{=}1\) with \(a{=}b{=}1\),
or an assumption repair). The failure mode under test is failure to omit an
irrelevant predictor / recover the minimal AND form, not necessarily
\texttt{completed\_no\_solution}.
Do \emph{not} take ``\(c\) becomes unlearnable'' as the primary hypothesis;
strong unlearnability wording may be refuted.

\subsection*{H2c --- sample-edge (in scope)}
If \(E^+\) for \(c\) realise only one value of \(D\), AAMAS may emit a single
spuriously \(D\)-conditioned conjunction that is sample-adequate but
population-inadequate.
\textbf{Decision:} H2c is in scope for the first H2 write-up.
