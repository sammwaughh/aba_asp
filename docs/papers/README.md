# Papers

This directory contains papers used as reference material for the Causal ABA Learning project.

The agent should use `docs/theory/theory_primer.md`, `docs/theory/background.tex`, `docs/theory/literature_review.tex`, and `docs/theory/paper_summaries/` before consulting PDFs.

PDFs are reference material only. They should not be treated as the primary operational context.

## Core papers

- Toni 2014 — ABA tutorial.
- Russo, Rapberger, Toni 2024 — Argumentative Causal Discovery / Causal ABA.
- Proietti, Toni 2024 — Learning ABA Frameworks.
- De Angelis, Proietti, Toni 2023 — ABA Learning via ASP.
- De Angelis, Proietti, Toni 2024 — Brave ABA Learning via ASP.
- De Angelis, Proietti, Toni 2025 — Greedy ABA Learning for Case-Based Reasoning.
