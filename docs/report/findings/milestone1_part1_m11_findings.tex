\section*{Central claim}
% ---------------------------------------------------------------------------

Under complete, noiseless \emph{target-mechanism} tables (one isolated predictor plus a
deterministic parent$\rightarrow$\texttt{x2} copy), target-wise ABA Learning with fixed
\texttt{folding\_mode: nd}, cautious semantics, and \texttt{relto} assumption introduction:

\begin{enumerate}
  \item \textbf{Binary encoding:} the learnt \texttt{x2} rule tracks the direct-parent
  \emph{role} and is invariant to learner-visible predictor order ($\sigma$) and variable-identity
  swap ($\pi$).
  \item \textbf{Categorical-3 encoding:} the learner \textbf{can} track the direct-parent role
  when the parent feature wins the first \texttt{select\_rule} match; $\sigma$-invariance
  \textbf{fails} under the default pipeline because BK block serialisation order fixes that
  first match, the entailment gate accepts or rejects it, and failed target entailment commits
  to assumptions without backtracking to the parent separator.
\end{enumerate}

This account is \textbf{ablation-supported} (ABL-100--107). It describes an ABA Learning
input-serialisation / search-control effect---not causal discovery and not Russo-style Causal ABA.

% ---------------------------------------------------------------------------
\section{Introduction: why this claim and what would falsify it}
% ---------------------------------------------------------------------------

\subsection{Motivation}

QI-002 returned a categorical rule citing \texttt{x0} where the expected direct parent was
\texttt{x1}. m1.1 asks whether that reflects failure to track the \emph{parent role}, confusion
with a fixed variable name, or sensitivity to the order in which predictors reach the learner.

We use a metamorphic design: eight deterministic cells (binary and cat3 $\times$ A/B/C/D)
derived from one canonical cell~A per encoding via $\sigma$ (predictor-order reversal) and
$\pi$ (exchange \texttt{x0}$\leftrightarrow$\texttt{x1}). At the data level each cell is one
\emph{isolated} non-parent plus a \emph{connected} parent$\rightarrow$\texttt{x2} pair---not
chain SCM sampling.

\subsection{Theoretical and implementation boundary}

The current bridge performs target-wise ABA Learning over tabular features. It does \textbf{not}
implement \texttt{arr}/\texttt{noe}/\texttt{indep}, d-separation, or stable extensions as DAG
hypotheses. Claims here concern parent-\emph{rule} recovery under stated controls only.

BK feature groups are serialised in \texttt{DataFrame} column order
(\texttt{argcausaldisco\_integration.py}); $\sigma$ permutes that order verbatim into
\texttt{bk.aba}. Rule IDs follow \texttt{read\_bk} file order and feed the \texttt{fwt} table
used by \texttt{select\_rule} (\texttt{folding.pl}).

\subsection{What would falsify the claim}

\begin{itemize}
  \item Reordering BK blocks on cat3~A (same data, E+/E$-$) does \textbf{not} recover the
  parent singleton (would falsify BK-order sufficiency; ABL-101).
  \item \texttt{folding\_mode(all)} on unchanged cat3~A BK \textbf{does} recover the singleton
  (would falsify the commitment-path story; ABL-105).
  \item cat3 C vs D under $\pi$ does \textbf{not} mirror A vs B (would falsify symmetry; ABL-100/103).
  \item Binary A vs B differs under $\sigma$ (would falsify the encoding moderator; ABL-107).
\end{itemize}

None of these occurred under the executed nd ablations.

\subsection{Status of this document}

Stages 0--6 (nd grid, trace mechanism, ablations) are complete and support the central claim.
A \textbf{targeted greedy comparator} on the same eight cells is planned as an m1.1 addendum
(\S\ref{sec:greedy}); full Milestone~1 Part~2 (M1.2) remains a broader nd vs greedy review.

\section{Investigation narrative}
% ---------------------------------------------------------------------------

This section records \emph{what we did, in what order, and why}---not merely what the outputs were.

\subsection{Stage~0: validate that $\sigma$ and $\pi$ reach the learner}
\label{sec:stage0}

\textbf{Why first.} If predictor order were canonicalised before BK generation, $\sigma$ would be
void and the metamorphic test would be meaningless.

\textbf{What we did.} Prolog-free fixture checks (\texttt{test\_m11\_fixtures.py},
\texttt{m11\_validate\_fixtures.py}): orbit relations, table/BK order alignment, minimal factorial
tables (binary 4 rows; cat3 9 rows).

\textbf{Outcome.} 8/8 PASS; requested column order equals BK block order.

\subsection{Stage~1--2: eight-cell nd grid and transformation square}
\label{sec:grid}

\textbf{Why.} Establish whether returned \texttt{x2} rules track parent \emph{role} across $\pi$
and are invariant to $\sigma$---the pre-specified success criterion.

\textbf{What we did.} \texttt{run\_grid} with \texttt{M11\_parent\_position.yaml}
(\texttt{folding\_mode: nd}, \texttt{folding\_steps: 15}, timeout 120\,s). Compared learnt rules
to expected one-literal parent separators; evaluated $\sigma$ and $\pi$ edges at rule level.

\textbf{Outcome (observation).} 8/8 \texttt{solved}. Binary: 4/4 exact singleton; all $\sigma$ and
$\pi$ hold. Cat3: 2/4 exact (B, C); A and D return three-rule assumption structures citing the
non-parent; $\sigma$ fails on both pairs; $\pi$ holds on B$\leftrightarrow$C only.

This $\sigma$ failure on cat3 triggered mechanistic investigation---we could not stop at a
verdict table.

\subsection{Stage~3--4: trace mechanism for cat3 A vs B}
\label{sec:mechanism}

\textbf{Why.} Supervisor guidance: ``order differs'' is insufficient; we need \textbf{why, when,
and how} on \texttt{prolog.stdout}.

\textbf{What we did.} Line-by-line comparison of cat3 A vs B on the first target fold of rote
positive \texttt{x2(A)<-[A=3]} (trace line~35). Traced \texttt{read\_bk} $\rightarrow$ \texttt{fwt}
$\rightarrow$ \texttt{select\_rule} $\rightarrow$ \texttt{gen2} entailment vs assumption path.

\textbf{Finding.} Same E+, E$-$, and BK rule multiset; $\sigma$ differs only in block
serialisation. ID~3 (third BK line) is the first subsuming match for \texttt{[A=3]}:

\begin{center}
\begin{tabular}{@{}llll@{}}
\toprule
Cell & ID~3 rule & Folded target rule & Entailment \\
\midrule
cat3 A & \texttt{x0\_val\_0(A):-A=3} & \texttt{x2(A) <- [x0\_val\_0(A)]} & \textbf{fails} (covers E$-$) \\
cat3 B & \texttt{x1\_val\_2(A):-A=3} & \texttt{x2(A) <- [x1\_val\_2(A)]} & \textbf{passes} (E$+$ only) \\
\bottomrule
\end{tabular}
\end{center}

Failed entailment on the first target fold commits to \texttt{alpha\_1} without backtracking to
the parent rule at ID~12; rote rules are consumed; assumption-augmented \texttt{x2} rules are not
re-folded. Trace shape: A 173 lines / 27 rules vs B 54 lines / 19 rules. D vs C mirrors A vs B
under $\pi$ (later confirmed by ablation audit).

\subsection{Stage~6: falsification-first ablations}
\label{sec:ablations}

\textbf{Why.} Stage~4 correlates BK order with outcome; ablations must \textbf{intervene} on one
link at a time per \texttt{milestone1\_part1\_ablations.md}.

\textbf{What we did.} Pipeline \texttt{m11\_ablation\_run.py} / \texttt{m11\_ablation\_audit.py};
config \texttt{M11\_ablations.yaml}. Gating: ABL-100 $\rightarrow$ ABL-101 (decision point) $\rightarrow$
102, 103, 105, 107; ABL-106 skipped (ABL-105 conclusive).

\textbf{Outcome.} All executed ablations matched predictions:

\begin{center}
\small
\begin{tabular}{@{}llllrrl@{}}
\toprule
ID & Intervention & first\_fold & entail. & trace & rules & Outcome & Verdict \\
\midrule

\textbf{Interpretation.} ABL-101/102: BK order is \textbf{sufficient} to flip cat3~A from
assumptions to singleton. ABL-105: engine folding mode alone is \textbf{not sufficient}.
ABL-107: binary $\sigma$-invariance holds because the parent predicate wins the first fold under
both BK orders---an encoding moderator, not a separate mechanism.

Artefacts: \texttt{causal/outputs/aba\_learning/grid/M11\_ablations/}; commit \texttt{93d51bf}.

\subsection{Evidence chain (nd, ablation-supported)}

\[
\sigma \;\Rightarrow\; \text{BK block order} \;\Rightarrow\; \text{first \texttt{select\_rule} match}
\;\Rightarrow\; \text{entailment pass/fail} \;\Rightarrow\; \text{singleton vs assumptions.}
\]

\begin{itemize}
  \item \textbf{Observation:} cat3 $\sigma$ fails at rule level (grid Stages 1--2).
  \item \textbf{Mechanism:} trace audit cat3 A vs B (Stage~4).
  \item \textbf{Intervention:} ABL-101 BK reorder restores singleton on A config; ABL-105 shows
  \texttt{folding\_mode(all)} does not.
  \item \textbf{Symmetry:} ABL-100/103 under $\pi$; binary moderator ABL-107.
\end{itemize}

The learner is not globally ``name biased'': the same parent rule appears when BK order favours it
(ABL-101). The failure is conditional on encoding (competing value predicates + fixed search path),
not on missing parent information in data or examples.

\subsection{Explicit non-claims}

Not chain discovery; not Russo-style Causal ABA; not a production fix to BK serialisation;
ablation BK edits are diagnostic only. Greedy-as-fix for cat3 $\sigma$ is \textbf{not} claimed
until the comparator run (\S\ref{sec:greedy}) is recorded.
