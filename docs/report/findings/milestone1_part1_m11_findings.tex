\begin{abstract}
This document reports the findings of experiment~M11 (m1.1), a metamorphic validity control
that asks whether target-wise ABA Learning recovers a rule for the target \texttt{x2} that
follows the \emph{direct-parent role}, rather than a fixed variable name or a fixed position in
the learner's input. The investigation uses complete, noiseless tables in which one predictor is
statistically isolated from \texttt{x2} and the other is a deterministic copy of the parent
(\emph{target-mechanism} tables). Under non-deterministic folding (\texttt{folding\_mode: nd})
with cautious semantics and \texttt{relto} assumption introduction, we find an encoding-dependent
split: the binary encoding passes all checks, whereas categorical-3 fails
representation-order invariance for a reason that is now ablation-supported under nd.
Stage~7 (greedy comparator) shows greedy restores cat3 rule-level $\sigma$ but produces
parent supersets on all cat3 cells rather than singletons.
\end{abstract}

% ---------------------------------------------------------------------------
\section*{Central claim}
% ---------------------------------------------------------------------------

We claim the following, for target-wise ABA Learning on the m1.1 fixtures under the fixed
learner configuration stated above.

\paragraph{Fixtures.} Each cell provides a complete factorial table over \((x0,x1)\) with
\texttt{x2 := parent} deterministically. One predictor is marginally independent of \texttt{x2}
(the \emph{isolated} non-parent); the other is the connected parent of \texttt{x2}. This is
\emph{not} observational data from a chain structural causal model.

\paragraph{Claim 1 (binary encoding).} The learnt rule for \texttt{x2} cites the variable that
occupies the direct-parent role. Moreover, that rule is unchanged when we apply either of the two
metamorphic transformations defined below: predictor-order reversal ($\sigma$) or
variable-identity swap ($\pi$).

\paragraph{Claim 2 (categorical-3 encoding).} The learner \emph{can} recover the expected
one-literal parent rule when the parent feature wins the first successful match in the engine's
\texttt{select\_rule} procedure on the first target fold. Under the \emph{default} pipeline,
however, $\sigma$-invariance fails: reversing the learner-visible order of predictors (while
holding parent identity fixed) can change the returned rule from the expected singleton to a
three-rule assumption structure that cites the non-parent. We account for this failure by a
specific chain of engine steps---background-knowledge (BK) block serialisation order fixes the
first matching rule identifier; the cautious entailment test on that fold either passes or
fails; and a failed test on the first target fold commits the run to new assumptions without
backtracking to a later BK candidate for the same rote equality.

\paragraph{Status of evidence.} Claim~2 is supported not only by trace inspection (cat3 A vs B)
but by targeted ablations ABL-100--107 (June 2026, commit \texttt{93d51bf}). These ablations
show that reordering BK blocks alone is sufficient to flip the cat3~A outcome, whereas changing
the engine folding mode to \texttt{all} without reordering BK is not.

\paragraph{Scope boundary.} The claim concerns an ABA Learning input-serialisation and
search-control effect under stated controls. It is \textbf{not} a causal-discovery result and
\textbf{not} an evaluation of Russo-style Causal ABA (no \texttt{arr}/\texttt{noe}/\texttt{indep}
machinery, d-separation, or stable extensions interpreted as DAG hypotheses).

\section{Introduction: why this claim, and what would falsify it}
% ---------------------------------------------------------------------------

\subsection{Motivation and research question}

In experiment QI-002 (QL2), a categorical chain fixture returned a rule for \texttt{x2} that cited
\texttt{x0}, while the pre-specified direct parent was \texttt{x1}. That discrepancy could mean
several different things: the learner might fail to track which variable \emph{plays the parent
role}; it might prefer a fixed name (for example always \texttt{x0}); or it might be sensitive to
the order in which predictors are presented in the background knowledge file, even when the
underlying table and examples are otherwise unchanged.

Experiment m1.1 separates these explanations using a small metamorphic design. The research
question is:

\begin{quote}
Under complete, noiseless target-mechanism tables, when the direct-parent and non-parent roles
are exchanged between \texttt{x0} and \texttt{x1}, and when the learner-visible predictor order
is independently reversed, does the learnt \texttt{x2} rule follow the variable occupying the
direct-parent role?
\end{quote}

\subsection{Notation: cells, encodings, and transformations}

We use two \emph{encodings} of the same abstract design: \textbf{binary} (values in \(\{0,1\}\))
and \textbf{categorical-3} (values in \(\{0,1,2\}\)). Within each encoding there are four
\emph{cells} labelled A, B, C, and D.

Each cell specifies (i)~which variable is the deterministic parent of \texttt{x2}, and (ii)~the
order in which the two predictors appear in the table and in the generated BK file. Cells A and
B use parent \texttt{x1}; cells C and D use parent \texttt{x0}. The non-parent is isolated at the
data level (no association with \texttt{x2} in the table).

Two transformations link the cells. We write them as $\sigma$ and $\pi$:

\begin{itemize}
  \item \textbf{$\sigma$ (representation-order / sigma):} reverse the learner-visible order of
  the two predictors in the table columns and in BK block serialisation, without changing
  variable names, values, example atoms, or which variable is parent.
  \item \textbf{$\pi$ (variable-identity / pi):} exchange the identities of \texttt{x0} and
  \texttt{x1} (names and values together), relabel graph roles accordingly, and fix \texttt{x2}.
  Predictor order is transformed consistently with the orbit definition in
  \texttt{handcrafted\_m11.py}.
\end{itemize}

Per encoding, the orbit is $A \xrightarrow{\sigma} B$, $A \xrightarrow{\pi} D$, and
$C \xrightarrow{\sigma} D$ with $C = \pi(B)$. A \emph{transformation square} checks whether
 learnt rules transform as expected when we compare pairs linked by $\sigma$ or $\pi$.

\subsection{Notation: learner outputs and success criteria}

For each cell we pre-specify an \emph{expected singleton rule}: a single learned clause for
\texttt{x2} whose body cites the parent variable (binary) or the parent's value predicate at the
positive class (cat3). For example, in cat3 cells with parent \texttt{x1}, the expected rule is
\texttt{x2(A) <- x1\_val\_2(A)}.

We classify outcomes as follows:

\begin{itemize}
  \item \textbf{Exact:} the returned solution matches the expected singleton (modulo syntactic
  normalisation).
  \item \textbf{Discrepant but solved:} Prolog reports a solution, but the target-headed rules
  form an assumption-based structure (typically three \texttt{x2} rules whose bodies cite the
  non-parent value predicates, plus contrary rules). This is the same structural class seen in
  QI-002 \texttt{chain\_cat3}.
  \item \textbf{$\sigma$-invariance holds} on a pair when the learnt rules agree across the two
  cells related by $\sigma$ (and similarly for $\pi$-equivariance).
\end{itemize}

Positive and negative examples are written $E+$ and $E-$. They are fixed per cell by the fixture
and are not altered in ablation runs that only change BK serialisation.

\subsection{Theoretical and implementation boundary}

The repository's \texttt{causal/} bridge performs \textbf{target-wise} ABA Learning: for m1.1 we
learn rules for \texttt{x2} only, with \texttt{x2} excluded from the BK feature groups. The
recovered rules are compared to a known parent role for diagnostic purposes. This is a
parent-\emph{rule} recovery proxy, not whole-graph causal discovery.

Implementation details matter for $\sigma$. The BK writer
(\texttt{argcausaldisco\_integration.py}) serialises feature predicates by iterating
\texttt{DataFrame} column order without sorting. Therefore $\sigma$ in the fixture propagates
verbatim into \texttt{bk.aba} block order. When Prolog loads the file, \texttt{read\_bk}
(\texttt{asp\_utils.pl}) assigns consecutive rule identifiers in file order. The folding table
\texttt{fwt} indexes literals under the key \texttt{=/2}; \texttt{select\_rule}
(\texttt{folding.pl}) walks candidate rule IDs and returns the first body that subsumes the
current rote equality. Later steps in \texttt{gen.pl} test cautious entailment of $E+$ and $E-$
(\texttt{gen2}) and may introduce assumptions (\texttt{relto} path when no prior assumption
exists).

\subsection{What would falsify the central claim}

We stated falsifiable predictions before running ablations (see
\texttt{milestone1\_part1\_ablations.md}). In brief:

\begin{itemize}
  \item If reordering BK blocks on cat3~A while holding data and $E+/E-$ fixed did \textbf{not}
  recover the parent singleton, BK order would not be sufficient to explain the A vs B split
  (ABL-101).
  \item If \texttt{folding\_mode(all)} on unchanged cat3~A BK \textbf{did} recover the singleton,
  the story that only BK order and first-fold commitment matter would be incomplete (ABL-105).
  \item If cat3 C vs D did not mirror A vs B under $\pi$, the symmetry account would fail
  (ABL-100 audit, ABL-103 intervention).
  \item If binary A vs B differed under $\sigma$, the encoding-moderator explanation would fail
  (ABL-107).
\end{itemize}

Under the executed nd ablations, none of these falsifiers occurred.

\subsection{Status of this document}

Stages 0--6 under \texttt{folding\_mode: nd} are complete: fixture validation, eight-cell grid,
transformation square, trace mechanism for cat3 A vs B, and falsification-first ablations. The
sections below narrate that work in order. Section~\ref{sec:greedy} reserves space for a
\emph{targeted greedy comparator} on the same eight cells (an m1.1 addendum). Milestone~1
Part~2 (M1.2) will later treat non-deterministic vs greedy folding more broadly; it is not
required to establish the nd mechanism reported here.

\section{Investigation narrative}
% ---------------------------------------------------------------------------

The following subsections describe what we did, in what order, and why each step was necessary.
The narrative moves from establishing that the metamorphic transforms are real in the pipeline,
to observing grid-level pass/fail, to explaining cat3 failure at trace level, to confirming the
explanation by intervention.

\subsection[Stage 0: validate that sigma and pi reach the learner]{Stage~0: validate that $\sigma$ and $\pi$ reach the learner}
\label{sec:stage0}

If the Python bridge canonicalised or sorted predictor columns before writing BK, then $\sigma$
would not change the learner's input and the metamorphic test would be void. Stage~0 therefore
had to precede any Prolog runs.

We ran two Prolog-free checks:
\begin{itemize}
  \item \path{causal/tests/test_m11_fixtures.py}
  \item \path{causal/scripts/m11_validate_fixtures.py}
\end{itemize}
Together these verify the $\sigma$ and $\pi$ orbit relations on fixtures, confirm that requested
predictor order matches table column order and BK block order, and check minimal complete
factorial tables (four rows for binary, nine for cat3).

All eight fixtures passed. Requested order equals table order equals BK group order. Stage~0
establishes that later $\sigma$ effects, if any, are not artefacts of silent reordering in the
bridge.

\subsection{Stages~1--2: eight-cell nd grid and transformation square}
\label{sec:grid}

The pre-specified success criterion for m1.1 is that learnt rules track the parent \emph{role}
and are invariant to $\sigma$ and equivariant to $\pi$ at rule level (with correct coverage).
Stage~1 runs learning; Stage~2 compares outcomes on linked pairs.

We executed the grid with:
\begin{itemize}
  \item runner: \path{causal/experiments/run_grid.py}
  \item config: \path{causal/configs/experiments/M11_parent_position.yaml}
\end{itemize}
Learner settings were held fixed: target \texttt{x2} only; \texttt{folding\_mode: nd};
\texttt{folding\_steps: 15}; \texttt{prolog\_timeout\_s: 120}; cautious semantics with
\texttt{asm\_intro(relto)} inherited from the QI-002-style defaults.

\paragraph{Grid outcome.} All eight cells returned \texttt{solved}. For binary, all four cells
returned the expected singleton and every $\sigma$ and $\pi$ edge in the transformation square
held. For cat3, cells B and C returned the expected singleton; cells A and D returned
discrepant assumption-based structures whose bodies cite the non-parent value predicates. On
cat3, $\sigma$ failed on both pairs (A$\leftrightarrow$B and D$\leftrightarrow$C). $\pi$ held on
B$\leftrightarrow$C but failed on A$\leftrightarrow$D because both ends of that edge are
discrepant in the same failure class rather than matching the pre-specified singleton.

\paragraph{Why we did not stop here.} A pass/fail table shows \emph{that} cat3 is
representation-order sensitive under nd; it does not show \emph{why}. Supervisor guidance
(June 2026) required granular trace and runner-level clarity before further tests. Stages~3--4
and the ablation programme followed from that requirement.

\subsection{Stages~3--4: trace mechanism for cat3 A vs B}
\label{sec:mechanism}

Cells cat3~A and cat3~B share the same parent (\texttt{x1}), the same $E+$ and $E-$, and the
same multiset of BK rules. They differ only in $\sigma$: the order of \texttt{x0\_val\_*} and
\texttt{x1\_val\_*} blocks in \texttt{bk.aba}. Stage~3 identified \emph{where} the Prolog traces
diverge; Stage~4 recorded \emph{why} that divergence changes the final rule.

We compared \texttt{prolog.stdout} from
\texttt{cells/m11\_cat3\_A/} and \texttt{cells/m11\_cat3\_B/}. Both runs proceed identically
until the first non-deterministic fold on the first rote positive literal for the target,
\texttt{x2(A)<-[A=3]} (approximately line~35 in the A trace). At that point \texttt{select\_rule}
must choose among BK rules whose bodies subsume the equality \texttt{A=3}.

Because $\sigma$ permutes block order, the rule that receives identifier~3 (the third line of
BK after the header comments) differs between A and B:

\begin{center}
\small
\setlength{\tabcolsep}{4pt}
\begin{tabularx}{\linewidth}{@{}lYYY@{}}
\toprule
Cell & Rule at ID~3 & Folded target rule & Cautious entailment of $E+/E-$ \\
\midrule
cat3 A & \texttt{x0\_val\_0(A):-A=3} & \texttt{x2(A) <- [x0\_val\_0(A)]} & \textbf{Fails} \\
cat3 B & \texttt{x1\_val\_2(A):-A=3} & \texttt{x2(A) <- [x1\_val\_2(A)]} & \textbf{Passes} \\
\bottomrule
\end{tabularx}
\end{center}

The isolated predictor fold in A covers negative examples as well as positives (the value
predicate is true on rows where \texttt{x2} is negative). Cautious entailment therefore fails,
and \texttt{gen2} commits to a new assumption \texttt{alpha\_1} rather than backtracking to the
parent separator rule that appears later in BK (for example at ID~12). The rote equality is
consumed; assumption-augmented \texttt{x2} rules are not eligible for later re-folding under
\texttt{nonintensional/1}. Subsequent folds on \texttt{x1\_val\_*} literals apply to contrary
heads \texttt{c\_alpha\_*}, repairing exceptions rather than producing a unified parent rule for
\texttt{x2}.

Quantitatively, cat3~A produces a long trace (173 lines, 27 ABA rules) with three assumption
branches; cat3~B produces a short trace (54 lines, 19 rules) ending in the expected singleton.
The pair cat3~D vs C is analogous under $\pi$ (non-parent-first BK leads to assumptions;
parent-first leads to singleton); this was later confirmed by ablation audit rather than by a
separate line-by-line write-up in the experiment record.

\paragraph{ABL-101 (primary causal test).} On cat3~A's data and examples, we replaced BK block
order with that of cat3~B while preserving the rule multiset. The run then matched B's trace
shape: first fold \texttt{x1\_val\_2}, entailment pass, singleton
\texttt{x2(A):-x1\_val\_2(A)}, 53 trace lines, 19 rules, zero new assumptions. This shows BK
serialisation order is \textbf{sufficient} to flip outcome on a fixed cell configuration.

\paragraph{ABL-102.} Inserting a single parent rule \texttt{x1\_val\_2(A):-A=3} at the top of BK
(raising rule count by one) also recovered the singleton. The lowest matching rule identifier,
not merely block-level narrative, determines the first fold.

\paragraph{ABL-105.} With BK unchanged from default cat3~A, we set \texttt{folding\_mode(all)}.
The run still produced the assumption triple (157 lines, 27 rules). Thus an engine folding-mode
change alone is \textbf{not sufficient} to recover the parent singleton; BK order remains the
decisive lever in the nd commitment story.

\paragraph{ABL-107 (encoding moderator).} Binary cells A and B both fold the parent predicate
\texttt{x1} first with passing entailment, even though $\sigma$ permutes BK order. Cat3 fails
$\sigma$ because multiple value predicates compete to subsume the same equalities and BK ID
order disambiguates them---a property of the categorical feature encoding, not a separate
engine bug.

All ablation runs referenced above used commit \texttt{93d51bf} of the repository.

\paragraph{Metamorphic verdicts under greedy.} Binary: unchanged (all $\sigma$ and $\pi$
hold). Cat3: rule-level $\sigma$-invariance \textbf{holds} on both pairs (A$\leftrightarrow$B
and D$\leftrightarrow$C return identical target rules), unlike nd. $\pi$-equivariance holds
on the tested pairs. \textbf{No} cat3 cell meets the pre-specified singleton criterion under
greedy; cells B and C \textbf{regress} from nd singleton to superset.

\paragraph{Mechanism (cat3 A).} Greedy trace (${\sim}$79 lines vs nd A ${\sim}$172): on the
first rote equality \texttt{x2(A)<-[A=3]}, \texttt{fold\_greedy} folds \texttt{x1\_val\_2}
then \texttt{x0\_val\_0}, producing a two-literal rule with passing entailment---no
assumption commitment. BK order still influences which predicates enter the fold sequence,
but the nd first-fold entailment failure path is avoided.

\paragraph{Answers to pre-specified questions.}
\begin{enumerate}
  \item Greedy does \textbf{not} recover the cat3~A singleton without BK reorder.
  \item Cat3 $\sigma$-invariance \textbf{holds at rule level} under greedy, but all cells
  are discrepant supersets, not singletons.
  \item Greedy matches nd on binary (sanity check passed).
  \item Greedy differs from nd on cat3 via a distinct search path (\texttt{fold\_greedy/2}),
  not via the nd assumption-commitment chain alone.
\end{enumerate}

\paragraph{Claim impact.} M11-C-004 resolved: greedy does \textbf{not} fix singleton
recovery; it restores cat3 rule-level $\sigma$ while uniformly producing parent supersets.
M11-C-003, C-006, C-007 (nd mechanism) unchanged.

\subsection{Evidence chain}

We summarise the logical structure of the nd evidence as follows:

\begin{center}
\small
\begin{tabularx}{\linewidth}{@{}Y@{}}
$\sigma \Rightarrow$ BK block order $\Rightarrow$ first \texttt{select\_rule} match
$\Rightarrow$ entailment pass or fail $\Rightarrow$ singleton or assumptions.
\end{tabularx}
\end{center}

\begin{enumerate}
  \item \textbf{Observation (Stages~1--2):} cat3 fails $\sigma$ at rule level while binary passes.
  \item \textbf{Mechanism (Stages~3--4):} cat3 A vs B traces identify the first-fold fork and
  failed entailment on the isolated predictor.
  \item \textbf{Intervention (Stage~6):} ABL-101 shows BK reorder is sufficient to restore the
  singleton on cat3~A; ABL-105 shows \texttt{folding\_mode(all)} is not sufficient without BK
  reorder.
  \item \textbf{Symmetry and moderator:} ABL-100 and ABL-103 support the $\pi$-mirror account;
  ABL-107 shows binary is not subject to the same competing-predicate ambiguity.
\end{enumerate}

The learner should not be described as globally biased toward a fixed variable name. The same
parent rule \texttt{x2(A):-x1\_val\_2(A)} appears on cat3~A when BK order is intervened
(ABL-101) even though default A returns assumptions. The failure mode is conditional on encoding
and on pipeline serialisation, not on absence of parent information in the table or in $E+/E-$.

\subsection{Explicit non-claims}

We do not claim chain structural discovery, Russo-style Causal ABA, or a production-ready fix
to BK generation in the bridge. Ablation BK edits are diagnostic interventions only. We do not
claim that greedy folding fixes cat3 $\sigma$ in the singleton-recovery sense (Stage~7 shows
rule-level $\sigma$ restoration with uniform parent supersets instead).

\section{Limitations and next steps}
% ---------------------------------------------------------------------------

\paragraph{Limitations.} The m1.1 fixtures use a single seed, no noise, and minimal complete
factorial tables. Results apply to target-wise learning on \texttt{x2} under one fixed nd
configuration. Cells cat3~A and cat3~D are \texttt{solved} but discrepant relative to the
singleton criterion. Coverage metrics \texttt{cov\_py} and \texttt{cov\_pl} disagree on
assumption-based rules; classifications in this document use \texttt{bk.sol.aba} and traces.
Ablation BK changes are post-hoc and do not alter the default bridge behaviour.
