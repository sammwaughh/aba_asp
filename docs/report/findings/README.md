# Milestone findings (supervisor-facing)

This directory holds standalone LaTeX logs of milestone experiment findings for supervisor review and sharing. These documents are **not** part of the interim report manuscript under `docs/report/manuscript/`.

Compile with `pdflatex milestone1_part1_m11_findings.tex` from this directory, or share the `.tex` source directly. Canonical evidence remains in the experiment records under `docs/experiments/` and the artefact paths cited in each findings file.
